Housing Resource Manager: 

A C++ console application that helps organize and manage affordable housing resources for students facing housing insecurity, eviction, or homelessness.

Purpose: 

This project was created to address a real-world issue affecting many community college students — lack of access to stable and safe housing. The application allows users (such as support staff, students, or case managers) to store, view, update, and delete housing listings in a simple, offline, menu-driven system.

It was built as part of an advanced C++ programming course and incorporates core object-oriented design principles.

Features:

- Add new housing resource entries (e.g., shelters, shared rooms, apartments)
- Search for a resource by ID
- Display all current resources
- Update or delete resource records
- Sort listings by monthly cost (ascending)
- Persistent data storage using binary file I/O (`housing.dat`)
- Clean class structure with `.h` and `.cpp` file separation

Technologies & Concepts:

- **C++11**
- **Object-Oriented Programming**
- **Vectors of Objects**
- **Encapsulation**
- **Function Abstraction**
- **Custom Sorting**
- **Binary File Stream (fstream)**
- **Header and Source File Separation**
